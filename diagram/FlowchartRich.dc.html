01
Documents arrive
Continuously, in mixed shapes and quality. Native text PDFs like this one. Scans and photographs with no text layer. Amendments to documents already in the graph.
PROTOTYPED EXAMPLE475 page framework agreement, 46 bound parts, definitions, forms, and more.
02
Profile it, and decide whether we understand it
Pick the rulebook for this document family, the unit names, numbering grammar and citation habits. Then checks that the rulebook truly fits (e.g. that it names terms we know, that the numbering system matches, that no text is left homeless). Each page is also routed up an extraction ladder. If a text layer exists, it's read, otherwise OCR methods are used, with triaging to more expensive fallbacks like vision models if disagreements arise between methods during sampling.
exampleA document opens with a string/prose phrase rather than numbering, failing a rulebook check. Thus, the system stops.
03
Read the pages into words with positions
Every word has its box on the page recorded. Headers and footers are found by position and repetition. Printed page numbers are kept alongside file ones. Part boundaries are found using domain heuristics, with other methods like where footer changes, font sizes, length distributions, and more. Tables, diagrams and illustrations have their own pipelines.
PROTOTYPE exampleThe definitions schedule is two columns and text wraps mid cell, so reading in lines left-to-right like with prose would shred it. It also contains tables within tables, and yellow highlights that are semantically meaningful.
04
Assemble a hierarchy of nodes
In the example document, Clause 3.1.2 nests under 3.1 under 3, all within a page that's within a document. In my architecture, a node holds text or holds children, never both. The hierarchy is checked against the printed page (e.g. a child's box must sit inside its parent's). Oddities are recorded, never repaired.
exampleThe brief says 35 clauses, a plain pattern finds 34, so the odd heading is hunted and its difference logged. A stray typo, rFramework, stays verbatim.
05
Load into the graph, safely rerunnable
Every node's identity is derived from its position, document, version, part, path, so loading twice updates rather than duplicates. Every load is snapshotted and reversible as a batch. A salience score is computed for ranking -- a function of how often connected nodes are referenced, the distribution of its citations, and other factors. Simple frequency is misleading.

References, found then resolved
A citation grammar finds the pointing words. This process will be optimized over time, by sampling entity namings that don't connect to references and seeing which are missed refs and why.
Vocabulary, declared and discovered
The definitions schedule gives about 300 capitalised terms. A discovery rule can find definition sites independently, and the two lists are diffed. Matching is case sensitive, longest match wins, abbreviations count as the term.
hard casesSentence starts, headings and typo dense text each route to their own narrow model check, then to review.
Concepts, for finding
A model tags each section with the ideas it covers, so an agent can narrow to a neighbourhood no keyword names. Tags are flagged as model derived and are never citable, and a tag that collides with a defined term is not created, the term stay canonical.
Embeddings, three altitudes
Leaves are embedded as raw text. Containers get a concatenation and a short summary vector. A hit on generated text must resolve down to real leaf text before anything is cited from it.
Quarantine, a person decides
The document stops, because a wrong tree would corrupt every citation built on it. The pipeline never guesses. A human chooses, and step 02 retries.
06
Evaluate, before anyone relies on it
Structural checks first, every character attached, numbering coherent, hierarchies agreeing with the tree. Then the derive and diff pass (the page map, outline and definitions list we derived against the ones supplied, every disagreement triaged). Then a hand labelled golden set for measuring effectiveness of other downstream deterministic processes, and others for aligning SLMs for narrow tasks. Periodic random sampling can help catch issues for humans to resolve.
gatesHealth and error thresholds should exist to block releases.
Review queue
Each item shows the sentence, the page image with the box drawn, and the candidates. Approve, pick, or reject. Minutes of judgement, not hours of reading.

[ HIGHLIGHT ]
References are nodes, not edges
This domain runs on cross references, so they are treated like things (nodes). A citation can fail, hesitate or need sign off, so it has a lifecycle and a status. It is like how in banking, a payment is not a relationship (dan PAID whitspace) but its own specific thing that can be examined, has metadata, etc.
[ HIGHLIGHT ]
Derive everything, then diff it
Nothing supplied is imported, the page map, outline and definitions are re-derived and compared.
[ HIGHLIGHT ]
Errors have different prices
A stray capital creates a phantom term, a missing one hides an obligation, and the second costs more. The eval reports a cost weighted confusion matrix with expert set weights, not bare accuracy.
