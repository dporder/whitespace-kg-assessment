Stage 0
Profile and fit
Pick the family rulebook, then five fit checks. Interpretation clause known, numbering matches grammar, no homeless text, depth in range, indentation agrees with numbering.
Extraction route per page, rising cost only when needed.
text layer layout OCR VLM last
Quarantine
Any check fails, the document stops with evidence attached. A person picks the rulebook. A wrong tree corrupts every citation built on it, so never parse anyway.
Deterministic structure
Stage 1
Parse
Words with boxes from the text layer. Headers and footers stripped by position and repetition, parts found by footer signature, tables and forms kept as cells with boxes.
per part, parallel
Stage 2
Assemble
Numbering becomes the tree. Branch or leaf rule, lead-ins as intro children. Geometric invariants cross-check tree against layout. Anomalies logged with the raw text kept, never repaired.
Identity
doc / version / part / path
Deterministic ids make reruns upserts. Lineage key names a clause across versions. Own and extent boxes per node, printed page kept.
Enrichment, concurrent after assembly
Stage 3
References, detect then resolve
Citation grammar plus orphan keyword scan. Resolution by the document's own scope rules, JS1 1.3.8 and 1.3.9. Refs are nodes with status, unresolved never disappears.

Stage 4
Vocabulary
Declared terms and rule-discovered definition sites, diffed. Case sensitive, longest match wins, aliases from parentheticals. Term-to-term DEFINED_USING from definition texts.
typed ambiguity routing stratified audits
Stage 5
Concepts
Per-section scan, Sonnet 5, resolved by embedding, collision guard so a term is never duplicated. Navigation only, never citable.
Stage 6
Embeddings and summaries
Three altitudes, leaf text, subtree within budget, summary above it. Vectors live in the index, not the graph.

Stage 7
Load
MERGE only on deterministic ids. Every node and edge batch-tagged, rollback and sweep tested. Salience is breadth times log-damped frequency. Access labels for role-scoped subgraphs. Replicas and snapshots on separate infrastructure.

Stage 8
Evaluate, every load
Structural and geometric invariants. Derived page map, outline and definitions diffed against the provided ones, disagreements triaged. Golden set scores detection and resolution separately, abstention scored, zero tolerance for a resolved unresolvable. Stratified audits of confident cases. Confidence calibrated against ground truth. Gates fail the load, exit 2.
judge: Haiku 4.5, separate prompt
Human loop
Review queue
Ambiguous and unresolved items with the page crop and the box drawn. Every decision appends to the golden set, which tunes the matchers and the judge. The human moves up a level over time, auditing the judge.
Consumers
Agents and analysts
Chat agent with bounded tools, read-only Cypher. Every claim carries path, page and box, and renders its source on click. Concepts narrow, structure answers.
The second document
Batches arrive continuously. Refs to absent targets sit unresolved, then flip to resolved when the target lands. Counted per batch in the eval report.
The hundredth
Idempotent by construction, upserts on deterministic ids, any batch reversible. LLM spend confined to residue and concepts, throttleable. Parts parallelise, resolution is the join.
The ten thousandth
New drafting family, new rulebook entry plus fixtures, never parser edits. Collections group frameworks with their call-offs. Cross-document resolution becomes scoped search plus review, not a bigger model.
