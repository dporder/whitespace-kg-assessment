# Evaluation. How I would know the graph is right

Dan Porder, 4 September 2026. Companion to `DESIGN.md`. The principle running through all of it is the one in the brief, a pipeline that is confidently wrong is worse than one that fails loudly, so every layer here is built to fail loudly, to say what it checked, and to say what it cannot check. The three tiers of the data model have different trust levels, so they are evaluated differently, deterministic structure against invariants and independent artifacts, the vocabulary against a declared list and human labels, the generative tier against duplicates, coverage and spot checks, never against itself.

## 1. What runs, in order of cost

**Layer 1, structural invariants. Free, every load.** The tree must be internally coherent before anything else is worth measuring. Children nest under their numeric parents, siblings ascend in reading order, numbering gaps exist only as recorded anomalies, every character of body text attaches to exactly one node, and every text bearing node's content round trips from its bounding boxes. The geometric checks cross examine the tree against the page, a child's box inside its parent's extent, indentation depth agreeing with numbering depth. These are the checks that answer the question Whitespace itself would ask first, does any legal document we throw in come out in the right structure, before anyone has used the graph at all. Distribution checks run beside them, clauses per page, leaves per clause, refs per clause, and a part whose numbers sit far outside the corpus distribution is flagged for eyes, the way an out of distribution anomaly should be.

**Layer 2, cross checks against the provided artifacts. Free, every load.** The assignment ships three descriptions of this document, a page map in the notes, a 498 entry outline embedded in the PDF, and a definitions schedule. The pipeline derives all three independently and diffs. The derived page map against the given one, per part. The derived tree against the outline, with every disagreement triaged into parser wrong, outline wrong, or both differ from the page, because the outline is itself machine generated from the source document's styling and degrades exactly where that styling was sloppy, so agreement is evidence but disagreement is not automatically our error. The discovered vocabulary against the declared list, as precision and recall of the discovery rule, plus the two interesting remainders, terms defined outside the schedule and capitalised phrases never defined anywhere. One concrete question this settles, the notes say 46 constituent parts and their own table lists 48 rows, and the derived map reports what the document supports.

**Layer 3, golden labels. Human time, so small and honest.** A hand labelled set of references and term uses, stratified across kinds rather than sampled conveniently, including deliberately unresolvable references, because abstention is a behaviour to score, not a failure to hide. Detection and resolution are reported as separate numbers, detection recall answers did we find the pointing words at all, resolution precision answers did we point them at the right target, and conflating them hides which half is broken. The set built tonight is tens of labels, the report prints absolute counts next to every rate so nobody reads 9 of 10 as 900 of 1000, and the growth path is section 3.

**Layer 4, stratified audits of the confident cases. Cheap LLM, every load.** Routing only self declared hard cases for checking would let a systematic error in the easy cases run silently. So a random sample of confident term matches and grammar resolved references, stratified by term length, part and position so it mirrors the population distribution, goes to an independent checker on every load, and sustained disagreement above threshold fails the gate.

**Layer 5, calibration. Every confidence number must have met ground truth.** Deterministic resolvers do not assert their own confidence, they carry the empirically measured precision of their class from previous evals. LLM resolvers emit a score in the same structured output as their ranked candidates, elicited before the final answer is committed so the model is not defending a conclusion it already stated, and those raw scores are calibrated against the golden labels per resolver, with a reliability table in the report, stated confidence bucket against observed precision. A threshold like "auto accept above 0.9" is only meaningful after that table exists.

**Layer 6, the generative tier's own checks.** Concepts are scored on duplicate rate after resolution, coverage, meaning sections that received no concepts at all, and a small human spot check per run. Concepts are navigation rather than citation, so the bar is usefulness and hygiene rather than fidelity, and the eval reflects that difference instead of pretending one metric fits all tiers.

## 2. Error costs are not symmetric

Two classifiers in this pipeline make thousands of small decisions, is this capitalised phrase a term use, is this phrase a citation. Each has false positives and false negatives with different costs. A false positive term use pollutes the graph and erodes trust in everything else. A false negative hides an obligation from the person searching for it, which in this domain is usually worse. The report therefore shows confusion matrices with per cell counts, broken out by ambiguity kind, sentence initial, heading, typo dense text, and a cost weighted summary whose weights are declared placeholders for a domain expert to set, because which error hurts more is a judgement about consequences, not about data. Typo density earns its place here, in text where spelling is unreliable, capitalisation stops being evidence in both directions, a stray capital mints a phantom term and a missing one hides a real use, so those sections are routed to their own narrow check and reported as their own stratum.

## 3. Where ground truth comes from, and how it grows

Tonight, from me, hand labelling against the page images. In operation, from the review queue, every human decision on an ambiguous reference or term use is appended to the golden set with reviewer and timestamp, so ground truth grows as a by product of operating the system rather than as an annotation project. The sampling frame matters more than the volume, the golden set should mirror the production distribution, stratified by part type, reference kind and ambiguity kind, not by what was easy to label.

The derive then diff pattern extends this to structure. Wherever the pipeline derives something a human artifact also describes, the tree, the page map, the vocabulary, a sampled subset of disagreements goes to a person who rules for the derived version, the provided version, or neither. Those verdicts do two jobs, they measure the deriver, and they tune it, with the improvement measured on documents the tuning never touched, which is the generalisation check that separates a better parser from a parser overfitted to one framework agreement.

Scaling the human out of the loop, deliberately and in stages. First an LLM judge is aligned to my labels on the same sample until it agrees with me at a measured rate, then it runs the layer 4 audits at volume. The next stage, which I have run in production on a customer service system, is fine tuning a small model on the accumulated human labels so the judge is cheap enough to run on everything, continuously. A variant worth having in the drawer, two different judge models scoring the same small sample independently, each also rescoring its own previous verdicts, agreement within and between models bounds how much to trust either. The human never disappears, the human moves up a level, auditing the judge on a stratified sample instead of auditing every case.

## 4. Regressions and release gates

Every run writes the same report shape, so regression is a diff between reports, not a feeling. The gates that fail a load, thresholds in `config.py`:

- Any structural invariant violation without a recorded explanation.
- Detection recall below threshold on the golden refs, or resolution precision below threshold on resolved ones.
- Any golden unresolvable that got resolved anyway. Wrong confidence is the failure mode this whole document exists to prevent, so this gate is zero tolerance.
- Stratified audit agreement below threshold.
- Node and edge counts failing to reconcile with stage outputs, or a rollback test failing to remove its batch completely.
- A quarantine signal firing, which stops the document before the graph, not after.

A release additionally requires the cross check diffs to have moved in the right direction, no new unexplained disagreement with the provided artifacts, and the calibration table to show no bucket where stated confidence exceeds observed precision by more than the declared margin.

## 5. Cost control

Evaluation is scoped, not monolithic. A routine batch evaluates the parts it touched, the full battery over the whole graph runs as a scheduled sweep rather than on every load, and the expensive layers, LLM audits and judge runs, sample rather than exhaust. The free layers run always, everywhere, because invariants and diffs cost nothing and catch the failures that matter most.

## 6. Implemented tonight versus written down

Implemented and running in this submission, the structural invariants, the three provided artifact cross checks, the golden harness with detection and resolution separated and abstention scored, the stratified audit sampler, the per batch resolution transition counts, and the gates with exit codes. Written down with a design but not run tonight, the calibration table beyond the first bucket counts, the cost weighted confusion matrix with expert weights, the judge alignment loop, and the retrieval A B for the neighbour window embedding variant, embedding each leaf with its previous and next sibling against embedding it alone, scored on retrieval hit rate over a fixed query set, which I would run before changing the default. The line between the two halves is drawn by the time cap, and everything in the second half has its measurement already specified so it is a task, not an idea.
